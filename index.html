    overview

    최근 리브랜딩된 CJ ONE의 브랜드 느낌이 기존 웹사이트에 잘 녹아 있지 않아, 로고와 사이트 분위기 사이에 어색함이 생기고 사용자들도 이를 불편하게 느끼고 있었습니다.
    전체 웹사이트를 새롭게 다듬고, 복잡하게 흩어져 있던 정보들을 핵심 위주로 간결하게 정리해 누구나 쉽게 원하는 내용을 확인할 수 있도록 개선했습니다.

    해당 모바일 목업은 SCSS를 활용하여 제작되었습니다.

    Problem & Solutions

    • Problem 01

      리브랜딩된 브랜드 컨셉과 웹사이트간의 괴리감

      리브랜딩된 컬러 시스템과 비주얼 가이드를 레이아웃, UI 컴포넌트, 인터랙션 전반에 적용해 브랜드 경험의 일관성을 강화

    • Problem 02

      정보 구조의 복잡성

      중요도 기준으로 콘텐츠를 재정렬하고 불필요한 정보를 축소해 사용자가 핵심 정보에 빠르게 접근할 수 있도록 개선

    • Main Visual

      CJ ONE의 스파클링 프리즘 콘셉트가 어두운 배경에서도 더욱 선명하게 반짝이도록 시각적 요소를 보완하고, 브랜드 메시지를 명확하게 전달하기 위해 슬로건을 크게 배치했습니다.

    • Keyword

      CJ ONE의 세 가지 키워드를 중심으로 브랜드가 전달하고자 하는 메시지를 시각적으로 구성했으며, 각 키워드에 어울리는 배경 이미지를 활용해 몰입감을 높였습니다.

    • Partner Brand

      다섯 개의 카테고리를 CJ ONE의 콘셉트에 맞춰 아이콘으로 리디자인했습니다.

    • EVENT

      메인 화면에서 이벤트로 빠르게 이동할 수 있도록 슬라이더 형태로 배치했습니다.

    • Lifestyle

      음식, 쇼핑 등 일상의 카테고리를 끊김 없이 흐르는 애니메이션으로 표현해, 일상의 경험이 자연스럽게 이어지는 브랜드 이미지를 강조했습니다.

    • APP Download

      QR로 간편하게 앱을 설치할 수 있도록 유도하고, QR 사용이 어려운 사용자들을 위해 휴대폰 번호 입력 폼을 함께 제공했습니다.

    02. 완벽한 하루 완벽한 하루 모바일 웹사이트 리뉴얼

    Go To Site
    • ContributionTeam Project (곽승현 조장 외 4명 / 프로젝트 평가 최우수상)
    • Duration3weeks
    • ToolFigma, HTML/CSS + JS/jQuery
    • DeployVercel
    • RangeMain 1 + Sub 14 Total 15page

    overview

    데이트 코스 구성에 어려움을 겪는 커플을 위한 장소 탐색부터 원클릭 예약까지 제공하는 올인원 어플 [완벽한 하루]를 리뉴얼했습니다. 직관적 UI와 자연스러운 흐름으로
    코스·예약 기능을 한눈에 잇는 트렌디한 사용자 경험 제공하도록 프로젝트를 설계했습니다.

    Problem & Solutions

    • Problem 01

      페이지 연결성이 부족해 흐름이 끊김

      정보 확인부터 예약, 코스 설계까지 흐름을 단순화하고 고정 예약 버튼으로 즉시 예약이 가능하도록 구성

    • Problem 02

      글만 있으니 몰입성이 떨어짐

      OTT형 영상과 리스트로 보는 재미를 높이고 스토리텔링 방식으로 데이트 코스의 분위기도 쉽게 파악

    • Problem 03

      메뉴 구조 복잡·UI 비직관

      전체 메뉴를 제공해 정보 구조를 명확히 보여주고 사진과 아이콘의 크기·계층을 정리해 구조를 명확히 함

    Typography

    페이퍼로지

    Pretendard - SemiBold

    Pretendard - Regular

    ICON
    Color

    Project Goal

    “함께 설계하는 설렘, 완벽한 하루로 이어지다”

    직관적 UI와 사용자 플로우로 코스·예약·추천이 한눈에 이어지고, 함께 만드는 경험을 부드럽고 몰입감 있게 즐길 수 있는 트렌디한 데이트어플로 사용자의 니즈를 충족시킵니다.

    Main Page

    아래 Detail View는 팀작업 중 개인 작업 부분입니다.

    • 화면 구성 기존에는 없던 전체 메뉴를 추가해 한눈에 사이트 구조를 파악하기 어려웠던 문제를 개선하고 사용자가 고민 없이 탐색 경로를 선택할 수 있도록 상단 카테고리 퀵버튼을 배치했습니다.
      또한 OTT형 숏폼 콘텐츠로 몰입도를 높이고, 사용자가 직접 구성한 코스를 메인에서 바로 확인·예약할 수 있도록 구성했습니다.

    • 동영상 팝업 숏폼의 영상 클릭 시 전체화면으로 팝업이 띄어져 크게 볼 수 있습니다. 코스 상세보기 버튼 클릭 시 해당 코스의 정보가 담긴 페이지로 이동합니다.

    • 원클릭 예약 코스별로 예약·결제를 반복해야 하는 번거로움을 줄이기 위해 패키지형 결제 시스템을 도입했습니다. 버튼 클릭 시 예약 모달이 슬라이드되며 코스 내 여러 장소를 한 번에 선택·예약할 수 있습니다.

    • 퍼펙트딜 필터링 퍼펙트딜의 카테고리 기준으로 장소를 필터링하여 빠른 탐색이 가능하도록 했습니다.

    Sub Page

    장소 상세페이지 해당 장소의 소개, 퍼펙트딜, 정보, 리뷰 등을 한 페이지에서 확인 가능합니다.
    섹션은 고정된 네비게이션으로 이동이 가능합니다.

    코스 상세페이지 코스에 포함된 장소들의 요약된 정보와 팁을 볼 수 있으며, 코스의 예상 비용과 소요 시간을 확인할 수 있습니다.

    Tiffany & Co는 티파니 블루라는 고유의 색을 색채상표를 가진 컬러 마케팅을 성공적으로 활용한 기업입니다. 너무 큰 이미지의 레이아웃과 복잡한 헤더 GNB로 소비자의 사이트 사용 시 피로도가 높을 수 있다는 문제점이 있습니다. 이러한 문제점을 해결하여 소비자의 피로도를 줄이는 것이 프로젝트의 목표입니다.

    • Problem 01

      이미지로 인해 복잡해 보이는 레이아웃

      이미지·아이콘 크기와 정보 노출량을 표준화하고 계층을 단순화해 레이아웃 복잡도를 낮춰 사용자 피로를 줄임

    • Problem 02

      복잡하고 정보가 많은 메뉴

      헤더 정보를 핵심 메뉴 중심으로 축약하고 여백·정렬을 그리드로 통일해 필요한 콘텐츠로 빠르게 진입할 수 있도록 개선
